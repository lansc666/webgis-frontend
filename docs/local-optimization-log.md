# 本地 UI 优化记录（2026-09-16）

约定工作窗口：北京时间 15:17:50–16:17:50（1 小时）。仅本地修改，不提交或推送远程。
起始版本：2d60641，分支 feat/ui-panel。地图、API、app.js 仍由团队其他负责人提供。

## 方向与取舍

使用者：完成课程作业的 GIS 学生；在桌面浏览器中选择图层、检查属性、提交编辑，并在手机检查结果。
目标：地图始终是焦点，能明确知道当前图层、选中对象、未提交状态和操作结果。
领域：图层、坐标网格、几何家族、要素、测绘图纸、属性记录、草稿与持久化。
自然色彩：纸白、地形绿、墨灰、水系蓝、测绘提示琥珀、错误红；后两者仅用于有语义的状态。
特征：地图／图层／属性三者围绕同一个当前要素；点线面标识与操作约束一致。
避免默认：纵向卡片堆积→地图+底部宽表；所有区域同等突出→工具和提交优先；装饰性玻璃效果→可读的测绘纸面。

视觉系统：14px 基准、12px说明、15px区标题、20px主标题；Segoe UI/微软雅黑中文正文，本地字体不引入网络依赖。
深度：细边界与纸面色阶；4px间距基准，面板16px，控件40px、手机44px；单一地形绿主操作。
每轮遵循：确认意图与层级 → 修改 → 自动回归 → 桌面/手机视检 → 修复本轮问题 → 下一轮。

技能使用：interface-design 提供产品方向和层级；ui-ux-pro-max 提供数据密集工具与可访问性建议；web-design-guidelines 提供规范审核。
ui-ux-pro-max 首轮 GIS 查询误匹配 VR，不采用；第二轮数据工作台匹配 Data-Dense Dashboard，采用密度/表格指导，不采用营销页面结构。
审核基准：https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md

## 基线

- 原有浏览器测试全部通过，保存 before-desktop.png / before-mobile.png 在 tmp/ui-tests。
- 问题：属性表位于窄侧栏；说明字偏小；表格重绘丢焦点；创建错误只在页底；缺少大数据表控制；主入口仍依赖手动改 URL 才能预览。

## 第 1 轮：布局与视觉系统（通过）

意图：学生能同时查看空间工作区与属性；层级：主地图、底部宽表、右侧图层/编辑；颜色/深度/字型/间距沿用上述系统。
改动：语义色彩变量、宽属性表、跳过导航、控件尺寸、聚焦态、减少动画偏好、强制颜色模式、长内容换行。
检查：原有浏览器测试全通过；1365px 桌面和 390px 手机截图核对。属性表宽度显著增加，长表仍局部滚动；手机顺序与 DOM 保持一致，避免键盘跳跃。预览日志占用地图的表现将在第 4 轮处理。

## 第 2 轮：键盘与操作反馈（通过）

意图：连续选要素和处理草稿时不丢失位置；层级：当前操作反馈优先于通用状态。沿用纸面色阶，错误红/草稿琥珀仅表示状态；14px 正文和 4px 间距。
计划：选择焦点保留、扩大复选框目标、字段级错误、保存/取消/删除反馈、草稿确认返回焦点。

检查：加入连续空格键选择、外部重绘焦点保留、字段错误关联、文件名显示和成功反馈断言。发现切层对话框取消后焦点回到旧按钮，修复为明确回到图层下拉框，再次回归通过。桌面/手机截图重新生成，桌面视检通过。

## 第 3 轮：属性表查找与大数据表现（通过）

意图：在最多 5000 个要素中找到记录；层级：搜索/筛选 → 数据 → 分页，选中状态不随翻页丢失。沿用 14px 字型与 4px 间距，以地形绿标记选择、数字使用等宽数字；不增加后端分页接口。

改动：本地搜索、仅看已选、数值/中文排序、每页50条、清除选择/筛选；完整集合仍保留；单页 DOM 限制在50行；中文输入法组合输入期间不提前筛选。
检查：5000要素测试的同步渲染耗时约7ms（本机单次测量，不含绘制，不承诺其他设备表现），页面100页；跨页选择、筛选不发选择事件、数字倒序、空结果、清空最后选中行的焦点均通过。桌面/手机截图检查通过。

## 第 4 轮：可理解的独立预览与引导（通过）

意图：学生直接打开页面就能找到体验入口，分清模拟与真实数据；层级：当前图层和对象优先，调试日志收起。沿用纸面、地形绿和网格，不伪装真实底图；图形为明确标注的示意数据。

改动：主页直接体验链接；内置一致线型图标；点/线/面示例数据；可选择的示意画布；可模拟新建、修改与提交；日志折叠。所有模式明确显示“模拟”，演示 ID 按模式使用正/负整数。
检查：原有回归+新建/恢复/切层/两模式测试通过；发现保存后示意按钮未解除禁用，修复后用断言覆盖。图形不代表真实底图/坐标，最多展示6个标记，完整记录仍在表格。桌面、手机截图检查通过。

## 第 5 轮：窄屏、键盘与规范审核（通过）

意图：在手机、横屏和键盘操作中同样可完成任务；层级：先提供直接导航，再保留当前操作上下文。保持相同纸面系统和语义颜色，手机44px目标、可放大文字，焦点环独立于选择框。

改动：窄屏快速导航，锚点移动焦点且不被吸顶栏遮挡；补齐链接/折叠区44px目标；边框对比度由2.88:1调整到3.36:1；极长属性改为可键盘滚动的局部区域，避免将保存操作推到页面数千像素之外。
检查：320/375/390/768/812横屏/1024/1440宽度均无页面横向溢出；可见控件名称、ARIA引用、重复ID、目标尺寸、语义色对比度检查通过；减少动画、强制颜色、深色系统偏好下的显式浅色表单、200%文字压力测试通过。正文色12.70:1，辅助文字最低测试值4.59:1。自动检查是针对本界面的回归，不等同完整WCAG认证或真实读屏器测试。

## 第 6 轮：边界状态与预览真实性（通过）

意图：任何状态都准确告诉学生“是否完成、是否保存、能否继续”；层级：失败保留草稿，模拟结果不得宣称数据库已修改。沿用地形绿与错误红，保持按钮与反馈区域位置稳定，不增加装饰。

改动：增加仅用于独立体验的可选 preview 显示标记（正式四方法与事件契约不变）；预览保存、删除、创建和后续重绘均使用模拟文案。保存/取消/删除错误显示在编辑操作旁，同时保留全局提示。草稿对话框补齐正向/反向键盘循环，Escape 仍回到原触发控件。
检查：部分异步状态不能提前解锁；失败重试保留完整属性；临时修改离开提示、恢复后清除提示；非法ID去重/禁选；空图层恢复；中文组合输入；纯表格模型不改源数据；预览新层创建与新增要素，全部通过。新增键盘测试发现原生弹窗最后按钮后焦点移出，修复后重跑全部测试通过。已视检弹窗、就近错误及两种模式。

## 第 7 轮：长表格可读性与收尾审查（通过）

意图：宽表格在小屏中仍能定位选择，长属性不挤走其他列；层级：要素选择与标识优先，全文在只读属性区查看。保持纸面色阶、44px行高、语义选中绿和紧凑列标题。

改动：冻结选择列；属性列最大280px、超长标题省略，原始全文保留在表格文本/提示及只读属性区；普通刷新保持表内滚动位置，分页/筛选返回首行；空值可按显示的null查找；清理旧预览样式。
检查：320/768/1440宽度下冻结列位置、最大列宽及全文保留断言通过；刷新保持700px滚动位置、下一页回到0通过；全量功能/规范回归与桌面手机视检通过。当前5000要素同步渲染约7–13ms，增加列宽测量与滚动恢复后仍远低于测试上限，不代表跨设备基准。

## 第 8 轮：完成反馈、联调说明与最终回归（通过）

意图：让下一位接手者清楚哪些可用、哪些只是模拟，成功操作能回到下一步。层级：完成反馈与后续入口；保持当前按钮、表单和状态语义，不新增框架或网络依赖。

改动：创建图层失败就近提示并保留名称；成功才清空并收起表单，回到图层选择。更新README与UI接入说明，列明辅助模块、展示层分页、可选预览显示标记、状态完成时序和测试边界。
检查：新增创建失败/成功与属性滚动保留测试；发现收起表单后浏览器未及时移出旧焦点，修复为在完成前记录原焦点归属，回归通过。全部测试、桌面/手机/弹窗/错误截图已核对。进入剩余工作窗口的最终只读复核，不再扩展功能范围。

最终入口视检补充：320px下占位图形被固定高度挤压，改为仅占位说明可见时随内容增高；真实地图/体验画布高度不变。新增普通入口、直接体验链接、非法预览参数、占位图形比例测试，全部回归再次通过。
